## Projetos em destaque

### [EPTRAN](https://github.com/EliasLuiss/Eptran)
Plataforma educativa sobre trânsito, com jogos (quizzes, jogo da memória, forca, caça-palavras e outros), área de conteúdo, vídeos e painel administrativo. Primeira versão em HTML, CSS e PHP e versão atual em Next.js com TypeScript.

### [Financiamento de Carros](https://github.com/EliasLuiss/AtividadeAvaliativaPOO)
Aplicação em Java com interface gráfica (Swing) que simula o financiamento de um veículo: valor financiado, parcela e total a pagar, com validação dos dados e classes separadas por responsabilidade.

### [Banco](https://github.com/EliasLuiss/Banco)
Simulador de conta bancária no console em Java, com saque limitado pelo cheque especial, depósito, consulta de saldo e validação de entrada, usando encapsulamento.

### [Elevador](https://github.com/EliasLuiss/poo_1_atividade_elevador)
Simulação de um elevador de 8 andares em Java, com controle de porta e de andar por menu, para praticar classes, métodos e condicionais.
